# Mission Learning Path

This suite is a training path, not passive documentation. Each mission asks you to open real files, annotate real code, answer questions, and self-grade. The missions use Infisical's actual stack: React 18, Vite, TanStack Router, React Query, Axios, Fastify, Zod, Knex/Postgres, and the secrets-management domain [CLAUDE.md:33-68].

Recommended pacing: complete one junior mission per sitting, one mid-level mission per longer work block, and one senior mission only after you can trace the secrets flow without notes. A mission is complete when you can explain the file ownership, input/output contract, and failure mode using file-and-line evidence.

Self-grade honestly. Strong answers name exact files and line ranges. Weak answers sound plausible but cannot point to source.
