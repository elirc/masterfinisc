# 04 — Code Reading Gym

Reading code is a trained skill: you annotate, you trace, you contrast good with bad, you review. Four workout types, all against real Infisical code, all self-graded.

| File | Workout | Count |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts: inputs, outputs, invariants, side effects, failure modes | 8 drills |
| [02-trace-tables.md](02-trace-tables.md) | Step-by-step value traces across layers | 4 tables |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to repo patterns | 8 pairs |
| [04-review-katas.md](04-review-katas.md) | Fake PRs to review with graded findings | 8 katas |

How to work: timebox each drill (15–25 min), write your answers *before* looking at the answer key/rubric, and say your reasoning aloud at least once per session — interviews are spoken, and reasoning that feels clear silently often falls apart aloud.
